    Sign in with a token

    Create a fine-grained personal access token with Repository access: Only select repositories (or All repositories) and Metadata: Read-only only. A classic token with repo scope grants unnecessary write access to every repository.

    Security note: This is not application-level authentication. GitHub enforces all access. The token stays in this tab's session storage, never leaves the browser except in requests to api.github.com, and is cleared after 60 minutes of inactivity. Revoke it when finished.
